    補足(文法・構文など) 自己学習用

    1. プリミティブ型・ラッパーオブジェクト

    • プリミティブ型

      • JavaScriptの基本的なデータ型で、値そのものを表す。具体的には、文字列、数値、真偽値、null、undefined、シンボルなどが含まれる。プリミティブ型は、値そのものを直接表現し、オブジェクトではないため、メソッドやプロパティを持たない。

    • ラッパーオブジェクト

      • プリミティブ型をオブジェクトとしてラップ(包み込む)するオブジェクト。 プリミティブな値を一時的にオブジェクトとして扱い、メソッドやプロパティを実装するために使用される。 JS,TSでは文字列型はstringがプリミティブ型で、Stringはラッパーオブジェクトである。 単純に文字列を使用したい場合にはstring型で宣言する。(Boolean型,Number型,BigInt型,String型,Symbol型,Null型,Undefined型など、その他プリミティブ型についても同様)

    2. オートボクシング

    • オートボクシング

      • プリミティブな値、変数に対しラッパーオブジェクトのメソッドを呼び出した場合、 オートボクシング機能により一時的にラッパーオブジェクトを生成する。処理を行ったのち、 結果を返しラッパーオブジェクトは破棄することでプリミティブな値、変数でもラッパーオブジェクトのように振るまえる。

    3. 同期処理・非同期処理

    • 同期処理

      • 同期処理とは通常のプログラムの上から下に処理する流れ（逐次処理）と同義で、 通常特別な実装を必要としない。

    • 非同期処理

      • 非同期処理とはひとつのプロセスの中で**スレッド(実行コンテキスト)**を切り替えて、 I/O処理などのスレッドの待ち時間中に他の処理を行う実行モデル。
    項目 説明
    async/await(Promise) js、tsで非同期処理のコードを見やすくするための構文。 (素のJSでも実装できるがネストが深くなる)
    async その関数が非同期処理を含み、常にPromiseを返すことを宣言する。awaitとセットで使用する。
    await Promiseの完了を一時停止して待つキーワード。awaitの後に書かれたPromiseが解決するまで、async関数の処理を停止しPromiseの完了後に次の処理に進む。
    Promise async関数(時間を要する処理)の最終的な結果を表すオブジェクト。非同期処理の成否を返す(値orエラー)。これ自体は処理の内容に関与しない。 処理の成功時には「解決（resolved)」を返し、失敗時には「拒否(rejected)」を返す。

    async/await(Promise)のサンプルコード

    Example

    async function sample():Promise{  
  await new Promise(resolve => setTimeout(resolve, 1000));  
// Promiseをnewして1秒待機してからvoidを返す非同期処理  
//sample関数の処理は一時中断され、1秒後に再開される。  
  console.log('非同期処理が完了しました');  
}  

sample();  
// 関数を呼び出し非同期処理を開始。  
console.log('非同期処理を開始します');`  
// この行はawait new Promise・・・より先に実行される。
